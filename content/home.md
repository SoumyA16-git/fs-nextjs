# Welcome to Blog App

A modern full stack application built with Next.js, React Server Components, Drizzle ORM, and PostgreSQL.

## Features

- **Server-Side Rendering & App Router**: Fast page loads and SEO-ready architecture.
- **Drizzle ORM**: Type-safe relational database queries and migrations.
- **NextAuth Authentication**: Secure credentials authentication with bcrypt password hashing.
- **Reading Lists**: Save blogs to your personal reading list and mark them as read.
- **API Token Access**: Generate API tokens for programmatic access to user resources.
